# Final Year Project
*Description*: 
QualiScan is an AI-powered computer vision system for automated product quality inspection and fruit freshness detection. It uses YOLOv11, OCR, and image processing to analyze images, detect defects, extract product information, and classify fruit freshness through a web-based application.

*Tools & Technologies*: 
React.js, CSS, FastAPI, Python, YOLOv11, Doctr OCR, MongoDB, Docker, Kubernetes

*My contribution*:
* Led project planning and coordination.
* Designed the system and user interface.
* Implemented and integrated **YOLOv11** for object detection.
* Worked on **OCR integration** for extracting product information from images.
